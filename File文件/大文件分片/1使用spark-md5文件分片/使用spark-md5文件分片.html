    普通的 md5：
        普通的 md5.js（如 blueimp-md5）的 md5() 方法期望接收的是字符串。
        当你把 ArrayBuffer 传给它时，它依然会将其强制转换为字符串 "[object ArrayBuffer]"，导致每个文件切片blob的哈希值都变成了相同的值。
        
    SparkMD5：
        SparkMD5 是 MD5 算法在 JavaScript 环境中的优化实现，重点解决了传统 MD5 在浏览器中处理大文件时的‌内存溢出‌和‌主线程阻塞‌问题。
        SparkMD5 并非替代 MD5 算法，而是让 MD5 在 JavaScript 环境中更高效、更稳定地运行，是前端文件处理领域的标准解决方案。
        
            典型应用场景：
                大文件上传校验‌：在上传前计算文件 MD5，与服务器比对以实现秒传或断点续传。
            ‌    数据完整性验证‌：下载文件后重新计算 MD5，确保传输过程未被篡改。
            ‌    实时流式哈希‌：对日志、视频流等连续数据进行增量哈希计算。
            
            使用建议：
                ‌小文件 < 100MB：可直接使用 SparkMD5.hash() 一次性计算，代码简洁。 
                ‌大文件 > 100MB：必须采用增量模式（new SparkMD5.ArrayBuffer() + 分块读取），并推荐配合 Web Worker 优化性能。
