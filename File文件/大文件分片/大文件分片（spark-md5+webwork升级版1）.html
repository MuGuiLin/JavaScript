大文件分片（Web Worker 终极版）

        
当前代码存在的两个核心问题：

        🚫 坑一：直接用浏览器打开 HTML 文件：
        Web Worker 必须 在 HTTP 服务器下运行（file:// 协议下会直接报错或静默失败）。
        ✅ 解决： 用 VS Code 的 Live Server 插件，或者在终端运行，然后访问 http://localhost:3000 (或对应端口)。
        
        🚫 坑二：importScripts 路径错误：
        Worker 里的路径是相对于 Worker 文件本身的，不是相对于 HTML。
        ✅ 解决： 确保 spark-md5.js 和 hashWorker.js 在同一个目录下，且代码写的是：importScripts('./spark-md5.js');
