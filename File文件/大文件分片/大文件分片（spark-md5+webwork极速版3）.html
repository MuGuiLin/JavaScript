把 CPU “榨干”并实现极速计算，需要引入 Worker Pool（线程池） 模式。
💡核心原理：
    1、主线程：只负责“切片”和“调度”。它把大文件切成小块，然后像发牌一样分发给空闲的 Worker。
    2、Worker 集群：根据 navigator.hardwareConcurrency（CPU 核心数）创建对应数量的 Worker。它们并行工作，互不干扰。
    3、零拷贝优化：利用 file.slice() 的特性，传递的是文件的引用（句柄），而不是复制几 MB 的二进制数据，内存占用极低。
