AbortController取消HTTP请求

在JavaScript中，使用AbortController和axios库来取消HTTP请求是一种常见的做法，特别是在需要中断长时间运行或不必要的请求时。

    /**
        * 注意：在调用  controller.abort () 之后，这个 fetch 无法恢复！！
        * 
        * 因为：AbortController 是一次性的，一旦 abort，这个请求 / 连接就永久作废，不能重启、不能恢复。
        * 
        * 具体为什么不能恢复？
        *      - abort() 会彻底关闭连接
        *      - 被中止的 signal 会永久标记为已中止
        *      - 同一个 fetch 无法再次启动
        *      - 没有 undo /resume 方法
        *      - 这是浏览器标准设计，没有任何办法恢复。
    */
