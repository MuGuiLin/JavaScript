fetch被abort()后无法“恢复”只能重新发起请求

在JavaScript中，使用AbortController和axios库来取消HTTP请求是一种常见的做法，特别是在需要中断长时间运行或不必要的请求时。

controller.abort() 是不可逆的操作：一旦调用，当前的 AbortController 和关联的 fetch 请求会永久终止，不能恢复 / 重启这个已终止的请求。

    唯一的解决办法：创建新的 AbortController + 重新调用 fetch。
   
    核心原理：
        abort() 会让请求抛出 AbortError 异常
        原控制器失效，必须新建实例才能发起新请求
        恢复 = 重新执行请求逻辑
